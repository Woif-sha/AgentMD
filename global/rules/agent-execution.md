# Agent Execution

Use parallel agents only when work is independent and the benefit exceeds coordination cost. Work serially when results are dependent or the task is small.

Apply these delegation criteria to work directed by skills.

- Assign exploration and analysis as read-only work.
- Give parallel editors non-overlapping file ownership and integration boundaries.
- Keep final decisions and integration with the coordinating agent or assigned reviewer.
- Avoid delegation layers that cost more than direct execution.
